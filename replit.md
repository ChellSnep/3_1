# Running this project

This is a plain HTML and JavaScript exercise. No dependencies, secrets, or external services are required.

Use **Run** to start the **Start application** workflow. It serves the project with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the web preview to view `index.html`. The page is currently blank because the imported exercise has no visible content. Add page content to `index.html` and JavaScript to `script.js`, then refresh the preview.

The Python server is for development, not production hosting.
